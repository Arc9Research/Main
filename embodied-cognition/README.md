# Embodied cognition

**GitHub label:** [`embodied-cognition`](https://github.com/Arc9Research/Main/labels/embodied-cognition) — use on [issues](https://github.com/Arc9Research/Main/issues) for this direction.

## Overview

How physical body traits—especially joint and tissue flexibility—might relate to cognitive style, and how body maps and proprioceptive precision might shape thinking. This is speculative, testable psychology and cognitive science, not clinical care.

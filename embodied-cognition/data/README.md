# Data — embodied cognition

## Allowed

De-identified group summaries, published task norms, synthetic/example CSV layouts, analysis scripts that do not embed secrets or private IDs.

## Not allowed

**No identifiable participant data:** no raw individual responses with demographics that enable re-identification, no video, no clinical identifiers.

## Format

Use `YYYY-MM-DD-short-description.ext` and document columns in a comment block or companion README. License: [CC BY 4.0](../../LICENSE) unless noted otherwise.

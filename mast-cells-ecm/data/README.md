# Data — mast cells & ECM

## Allowed

De-identified cohort-level marker summaries, public omics accession lists, simulated matrix-assembly readouts for methods testing.

## Not allowed

**No identifiable participant data** or patient-linked biospecimen metadata in this public repo.

## Format

Name with date prefix; describe assay, units, and de-identification steps in README text. [CC BY 4.0](../../LICENSE).

# Data — regulatory genomics

## Allowed

Public variant lists (dbSNP / gnomAD IDs), model output ranks with no individual genomes, benchmark labels from public sources.

## Not allowed

**No identifiable participant data:** no individual VCFs, no linked clinical phenotypes for named patients.

## Format

JSON or TSV with a schema note; cite build (GRCh38, etc.). [CC BY 4.0](../../LICENSE).

# Hypermobility & collagen matrix

**GitHub label:** [`hypermobility-collagen`](https://github.com/Arc9Research/Main/labels/hypermobility-collagen)

## Overview

Structure and mechanics of collagen-rich tissue in hypermobile Ehlers–Danlos syndrome (hEDS) and related conditions, and how matrix quality might affect proprioception and joint position sense—mechanical pathways, not “dry collagen piezoelectricity” as the main story.

# Data — hypermobility & collagen

## Allowed

De-identified aggregate imaging or mechanics summaries, public variant IDs, synthetic fibril-metric examples for pipeline tests.

## Not allowed

**No identifiable participant data:** no patient-linked imaging files, biopsy metadata tied to individuals, or HIPAA-covered clinical fields.

## Format

`YYYY-MM-DD-short-description.ext` with units and provenance documented beside the file. [CC BY 4.0](../../LICENSE) by default.

## Ways to participate

### Share data or prior work

If you have datasets, pilot results, null findings, or methods relevant to a [project](README.md#current-highlighted-projects):

1. Open an issue with the **[I have related data / prior work](https://github.com/Arc9Research/Main/issues/new?template=related-data.yml)** template and select the project.
2. Or email **[arc9research@gmail.com](mailto:arc9research@gmail.com)** (no HIPAA-protected or identifying patient data in public threads).

Per-project `data/` folders accept **de-identified** artifacts only—see each project's `data/README.md`.

### Collaboration

For co-design, IRB planning, lab access, or recruitment, start a [Discussion](https://github.com/Arc9Research/Main/discussions) or an issue with the project label.

### Funding interest

Use the **[Funding interest](https://github.com/Arc9Research/Main/issues/new?template=funding-interest.yml)** template.

### Critique and corrections

Welcome in Discussions, Issues, or a dated note in the relevant project's `updates/` folder.

## What we cannot accept

- Medical advice posed as conclusions from this repo
- Identifiable participant data in the repository or public issues
- Claims of endorsement without explicit agreement

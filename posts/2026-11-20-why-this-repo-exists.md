# Why this repo exists

**Date:** 2026-11-20

I'm Grayson—an independent researcher without a formal lab affiliation, learning in public. I care about how bodies and minds connect, especially around connective tissue and hypermobility, and I keep running into questions that feel too small for a grant but too big to sit in a private notes file.

This repository is the **about page and notebook**—read it on GitHub. The root README introduces who we are and highlighted projects; each direction has its own folder with experiment posts, updates, and data guidelines. If an idea is wrong, I want it visible so someone can show me why. If you have already run something adjacent, I would rather link your work than reinvent it.

What you will find here:

- **Project folders** — open questions, experiment posts, references, and per-project logs.
- **`posts/`** — occasional repo-wide notes like this one, not claimed discoveries.
- **Issues and Discussions** — data, collaboration, or funding offers, tagged by project when possible.

I'm slow to claim and quick to revise when data disagree. Thanks for looking.
